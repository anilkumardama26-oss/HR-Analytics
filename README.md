# 📊 HR Analytics Dashboard

## 🔎 Project Overview

The **HR Analytics Dashboard** is a data analytics project designed to analyze employee data and generate meaningful insights into workforce performance, employee attrition, salary trends, attendance, and overall HR operations.

The project demonstrates how raw HR data can be cleaned, analyzed, and transformed into interactive dashboards and actionable business insights.

## 🎯 Objectives

* Analyze employee attrition and identify major factors affecting employee retention.
* Understand salary distribution and salary trends across departments and roles.
* Analyze employee performance and attendance patterns.
* Identify workforce trends and key HR metrics.
* Create interactive visualizations for better decision-making.
* Convert raw employee data into meaningful business insights.

## 🛠️ Technologies Used

* **Excel** – Data cleaning, preprocessing, formulas, and initial analysis
* **Python** – Data cleaning, exploratory data analysis (EDA), and visualization
* **Power BI** – Interactive dashboard and data visualization
* **Pandas** – Data manipulation and analysis
* **Matplotlib / Seaborn** – Data visualization

## 📈 Key Analysis Areas

* Employee Attrition
* Department-wise Employee Analysis
* Salary Analysis
* Employee Performance
* Attendance Analysis

* Age and Gender Distribution
* Workforce Trends

## 💡 Business Insights

The analysis helps HR teams understand employee behavior, identify attrition patterns, monitor workforce performance, and analyze salary and attendance trends.

These insights can support data-driven decisions related to **employee retention, workforce planning, performance management, and HR operations**.
